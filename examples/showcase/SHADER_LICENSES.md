# Bundled shader sources

Five examples are unchanged copies from [0xhckr/ghostty-shaders](https://github.com/0xhckr/ghostty-shaders)
at commit [`85898f08`](https://github.com/0xhckr/ghostty-shaders/tree/85898f08fcf4a9274e418912098e99e00a5f8350).
They are bundled locally. The page never downloads shader code from GitHub.
